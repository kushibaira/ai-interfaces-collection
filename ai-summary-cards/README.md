# AI Summary Cards

## What is this UI pattern?
A card that takes a long piece of text and shows a short AI-generated summary, key points, and a confidence tag. Users can switch the summary length, copy it, or regenerate it.

## Where is it commonly used?
Notion AI, email apps, meeting tools, Google search overviews and document readers.

## Why is it relevant to modern web interfaces?
People have more content than time to read it. Summary cards give the main idea quickly, while still letting users check and control the result.

## Design and interaction patterns I observed
- Short summary at the top, followed by bullet key points
- Confidence or source indicator on the card
- Copy and regenerate buttons
- Tone or length selector (short and detailed)
- Thumbs up and down feedback

## What my implementation does differently
- Paste your own text and get a simulated summary
- Short and detailed length selector
- Expand and collapse key points
- Dark and light theme
- Plain HTML, CSS and JavaScript only

## Technologies
HTML5, CSS3, JavaScript

## How to run
Open `index.html` in a browser.
